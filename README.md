> "I don't want my desktop to dance. I want it to **work** — fast, clean, focused." – Me after testing too many DEs 😂

As a 17-year-old self-taught developer from Iran (Lua for MTA:SA, Bash automation, Python scripting, limited internet, GitHub commits anyway), I tested multiple Linux distributions and desktop environments to find what actually helps me **code faster** instead of fighting the system.

This repo is my honest, no-BS review — what worked, what sucked, and what I recommend.

## Distributions I Tested

| Distro          | Stability | Ease of Use | Package Manager | Best For                          | My Verdict (1–10) | Recommendation |
|-----------------|-----------|-------------|------------------|-----------------------------------|-------------------|----------------|
| Ubuntu          | ★★★★☆     | ★★★★☆       | apt + snap       | Beginners, daily dev              | 8/10              | Great starter  |
| Debian 13 (Trixie) | ★★★★★   | ★★★★☆       | pure apt         | Stability, servers, serious work  | 9.5/10            | **My current main** |
| Arch Linux      | ★★☆☆☆     | ★☆☆☆☆       | pacman           | Extreme customization learners    | 4/10              | Avoid unless masochist |
| EndeavourOS     | ★★★☆☆     | ★★★☆☆       | pacman           | KDE lovers, tinkerers             | 6/10              | Only if you love rice |
| Kali Linux      | ★★☆☆☆     | ★★★☆☆       | apt              | Pentesting / security only        | 5/10 (daily use)  | VM only – not daily |
| Pop!_OS         | ★★★★☆     | ★★★★☆       | apt              | Gaming + dev                      | 8.5/10            | Excellent if you game |

## My Current Setup (2026)

- **Base**: Debian 13 (Trixie)  
- **Display Manager**: LightDM  
- **Main DE**: LXQt (daily driver)  
- **Backup DE**: XFCE (when I want a bit more panels/menu)  
- **Tools**: VS Code (Settings Sync + GitHub), tmux, git, python3, lua, bash, htop, neofetch 😄

## Quick Advice for Devs Like Me

- Want **stability**? → Debian 13 or Ubuntu LTS  
- Want **speed & zero distractions**? → LXQt or XFCE  
- Gaming + dev? → Pop!_OS with COSMIC  
- Love rice/customization? → EndeavourOS + KDE  
- Security tools only? → Kali in VM  
- Avoid Arch unless you have time to burn
